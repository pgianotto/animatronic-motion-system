ANIMATRONIC MOTION TRACKING SYSTEM - ROADMAP
=============================================

HOW TO LAUNCH
--------------
  python "z:\Python Projects\Motion Tracking Animatronic\main.py"

  Or if your terminal is already in the project folder:
  python main.py

  On Raspberry Pi (same command, hardware.type in config.yaml handles the rest):
  python3 main.py

HARDWARE TARGETS
-----------------
- Raspberry Pi 4 (primary deployment for live tracking)
- Windows PC (motion capture / sequence programming tool)
- USB camera (any UVC-compatible)
- PCA9685 16-channel PWM servo driver (I2C, recommended for Pi)
- Standard RC servos for pan/tilt
- Optional: Arduino + serial bridge for more servo channels

TRACKED VALUES -> XLIGHTS CHANNELS (DEFAULT MAPPING)
------------------------------------------------------
  head_yaw          -> ch 1  (Head Pan)
  head_pitch        -> ch 2  (Head Tilt)
  head_roll         -> ch 3  (Head Roll)
  mouth_open        -> ch 4  (Jaw / Mouth)
  left_eye_open     -> ch 5  (Left Eye)
  right_eye_open    -> ch 6  (Right Eye)
  left_eyebrow      -> ch 7  (Left Eyebrow)
  right_eyebrow     -> ch 8  (Right Eyebrow)
